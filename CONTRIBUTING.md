# Contributing

This private alpha is not yet open for public contributions. Preserve read-only scope and use synthetic fixtures. Never put real workspace content or credentials in tests, issues or commits.

Run npm ci --ignore-scripts and npm run check. BUZZ_CONTEXT_TEST_KEYRING=1 enables a disposable-key OS store test that removes its own entry. Record exact versions/state tested. Keep claims aligned with docs/VERIFICATION.md. Follow repository/runtime attribution; public publication needs maintainer approval.
